An entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty on make.fun.

The program (`main.ts`, Node 22) writes a single sentence pitching a ridiculous invention that fixes a tiny everyday annoyance — the washing machine that keeps eating socks — to `/output/entry.txt`.

> A washing machine that mails a ransom note every time it swallows a sock, demanding one biscuit for its safe return.

The sentence is 116 characters, one sentence, plain UTF-8 text.

## Run

```sh
node main.ts
cat /output/entry.txt
```
